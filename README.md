# My Sweet Cuisine

Projeto de site para uma confeitaria / cozinha doce, com foco em aparência agradável, navegação simples e apresentação de receitas e produtos.

## Sobre

Este repositório contém o código de um site de culinária doce, ideal para padarias, confeitarias ou blogs de receitas. O objetivo é mostrar produtos, receitas e informações de contato de forma clara e visualmente atraente.

## Instalação

1. Clone o repositório:
   ```bash
   git clone https://github.com/saarrr-alves/my-sweet-cuisine.git
   ```
2. Abra a pasta do projeto:
   ```bash
   cd my-sweet-cuisine
   ```
3. Instale as dependências necessárias do projeto:
   ```bash
   npm install
   ```
4. Execute no terminal do projeto:
   ```bash
   npm run dev
   ```
   Este comando inicia o servidor de desenvolvimento local e permite visualizar o site no navegador, geralmente em http://localhost:3000 ou outra porta informada no terminal.

## Uso

- Navegue pelas seções do site para ver receitas, produtos e informações de contato.
- Personalize imagens, textos e cores conforme necessário.
- Use o HTML e CSS existentes como base para futuras melhorias.
